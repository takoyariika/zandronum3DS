# Zandronum 3DS

alpha **0.1.18** / エンジン **Zandronum 3.2.1**。New 3DS・New 3DS LL・New 2DS LL向けの実験的な移植です。特定のMODは不要です。

## インストール

配布ZIPをSDカードのルートへ展開し、`cia/zandronum.cia` をインストールします。自分のベースゲームIWADを `SD:/3ds/zandronum/` に置いてください。MODは任意です。更新時は `args.txt` も上書きしてください。以前の選択は `launch.txt` に保存されています。MODを外すにはランチャーでXを押します。

ゲーム内の「ゲーム終了」はファイル選択ランチャーへ戻ります。ゲーム・音声・通信を終了してから選択画面に戻るため、そのまま別のIWAD/MODやネットモードを選び直せます。アプリを終了して3DSのHOMEメニューへ戻るには、ランチャーで **B**、または下画面右下の **B Exit to HOME** をタッチしてください。

エンジンの `zandronum.pk3`・`zandronum.pk3.3ds-resources`・`zandronum.pk3.3ds-cache` は同じフォルダーへ配置します。キャッシュは自動使用されるため、MODとして選択しません。元ゲーム・第三者MOD・Nintendoファームウェアは配布物に含まれません。

## ファイル選択とネットプレイ

十字キーで移動、L/Rでページ切り替え、AでIWAD選択・MOD切り替え、XでMOD解除、STARTでオフライン起動、Yでネットモード、BでHOMEへ戻ります。SDフォルダーと3階層までのサブフォルダーからWAD/PK3/ZIPを検出します。選択したMODは選択順に読み込みます。

ネット一覧は [doomlist.net](https://doomlist.net/) の3.2.1互換サーバーを表示します。Yで本体キーボード検索、SELECTでホスト名/IPとポートを入力します。省略時のポートは10666です。Aで必要ファイル、Xで不足MODをダウンロード、STARTで接続します。一覧内のアドレスはサーバー指定の読み込み順とパスワードを使用します。一覧外は現在選択したIWAD・MODで接続します。

## ダウンロードと再利用

完成したファイルは **`SD:/3ds/zandronum/downloads/` に保存され、終了・再起動後も残ります**。次回起動でも自動検出し、別サーバーやオフラインプレイで再利用できます。取得済みファイルは上書き・再取得しません。更新時にこのフォルダーを削除する必要はありません。ベースゲームIWADは所有者が配置します。

2 MiB以上のファイルは、配布先がバイト範囲要求とETag/Last-Modifiedによる同一内容の確認に対応していれば、**2接続で並列分割取得**します。非対応の場合は1接続を使います。SD書き込みを64 KiBでバッファリングし、並列受信は各128 KiBでまとめて保存します。待機を短縮し、操作確認・画面更新の頻度を抑えています。画面にKiB/sと接続数を表示します。Wi-Fi・配布先・暗号処理・SD速度によって効果は変わり、倍速を保証するものではありません。

最大512 MiB、受信長とPWAD/PK3識別を確認してからファイルを確定します。Bまたはキャンセルボタンで停止でき、失敗した部分ファイルは削除します。完成した他のファイルは残します。HTTPS証明書とホスト名を検証するため、本体の日付を正しく設定してください。取得結果は `download.txt`、一覧更新結果は `network.txt` に保存します。通常プレイ中の定期音声ログ・診断書き込みはありません。

1接続へ切り替える場合は、同梱の `args-download-single.txt` を `args.txt` に置き換えます。

## ゲーム操作

| 操作 | 機能 |
|---|---|
| スライドパッド上下 / 左右 | 前後移動 / カメラ旋回 |
| Cスティック・タッチドラッグ | 視点 |
| A・L / R | メイン射撃 / サブ射撃 |
| B / Y / X | ジャンプ / しゃがむ / 調べる・使用 |
| ZL（L2） / ZR（R2） | 前の武器 / 次の武器 |
| START / SELECT | メニュー / オートマップ |
| 十字キー上 / 下 | 次の武器 / 前の武器 |
| 十字キー左右 | ストレイフ |
| 下画面右上を押している間 | 低速移動（通常は常時ダッシュ） |
| 下画面左上をタップ | ログ / スコアボード切り替え |

0.1.16以降の初回起動で旧ボタン・軸設定を一度だけ移行します。0.1.17以降の初回起動では常時ダッシュを有効にし、以降の設定変更は保存します。設定ファイルを削除する必要はありません。メニュー操作はA決定・B戻る・十字キー移動です。

下画面はメニューと同じ紺色・青緑の配色です。左上で最近のログとスコア一覧を切り替え、人数が多い場合はスコア画面の最下部タップでページを送れます。右上は押している間だけ歩行し、離す・枠外へ移動する・メニューを開く・スリープ復帰で解除します。ボタンより下のドラッグは視点移動です。ログは固定128行の履歴から直近15行を表示します。

入力・APT処理が描画や音声復帰から再び呼ばれた場合の二重実行を防ぎます。実機で報告された「WIN表示からリザルトに切り替わる前にHOMEへ戻る」問題の原因は未確定です。`transition.txt` に画面切り替え、`apt-exit.txt` にAPT終了要求、`quit.txt` にゲーム側の終了を記録します。各記録は起動ごとに更新するため、再発時は再起動前に保存してください。通常プレイ中の定期書き込みは追加していません。

オンラインの観戦中は **Aで参加メニューを開き、Aで参加を決定**します。従来のSpace要求を3DSではAへ変更し、観戦中の案内もAと表示します。クラス・チーム選択が出た場合は十字キーで選んでAで決定します。

追加操作はゲーム内Customize Controlsで設定できます。オフライン起動ではSOC・DNSを使用しません。config・save・downloadはSDに保存します。致命的なエラーは `fatal.txt` に記録し、エラー画面のSTARTでHOMEへ戻ります。

## 任意のリソースキャッシュ

WindowsでWAD/PK3/ZIPを `tools/Build-ResourceCache.cmd` へドロップすると、リソースキャッシュを作成します。複数ファイルの同時ドロップも可能です。WADはIWAD/PWADの両方に対応し、画像・音声・マップ・スクリプトを含む全lumpを保存します。例えば `DOOM2.WAD` から `DOOM2.WAD.3ds-resources` ができます。WADは元から非圧縮なので、キャッシュも同程度のSD容量を使い、速度改善の程度は内容によって異なります。

PK3/ZIPでは `.3ds-resources` とPNG登録用の `.3ds-cache` を作成します。PNG登録のみなら `tools/Build-TextureCache.cmd` を使用します。このツールへWADを渡した場合も、自動的にWAD用の `.3ds-resources` を作成します。元ファイルと生成ファイルを同じSDフォルダーに置き、元ファイルを変更したら再生成してください。キャッシュをMODとして選択したり `args.txt` に追加したりする必要はありません。ZIP64・暗号化ZIPは未対応です。

## 検証と制限

ソフトウェア描画400x240、NDSP/CSND音声を使用します。Citraで接続・入力・HTTPS・ダウンロード・正常終了を検証しますが、実機のWi-Fi速度・発音・キーボード操作・FPSは実機確認が必要です。アカウント認証・UPnP・動画/CD再生は未対応です。通常起動引数には診断フラグを含めません。必要な場合だけ `-3ds-diagnostics` を指定します。詳細な変更・検証記録は `PORT_STATUS.md` にあります。
